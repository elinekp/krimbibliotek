# 🔍 Digitalt Krimbibliotek

Dette prosjektet er et digitalt økosystem for krimlitteratur, bygget med **Django** og **React**. 
Målet er å kombinere en personlig samling med en formidlingsportal basert på bibliotekfaglige prinsipper.

## 🏗 Metodikk
* **LRM (Library Reference Model):** For strukturering av verk, forfattere og utgaver.
* **Lesersørvis:** Bruk av appellfaktorer for å hjelpe brukere med å finne sin neste leseopplevelse.

## 🚀 MVP (Minimum Viable Product)
- [ ] Database for **Verk** og **Forfattere**.
- [ ] Taksonomi for krimsjangre og appellfaktorer.
- [ ] Enkelt brukergrensesnitt for søk og filtrering.
- [ ] Dokumentasjon av prosessen.

## 🛠 Teknologi
* **Backend:** Django (Python)
* **Frontend:** React
* **Versjonskontroll:** Git/GitHub
